# U2-ejercicio25
# Sistema de Notificaciones Omnicanal

**Objetivo principal:** desarrollar un sistema modular de notificaciones en Java utilizando interfaces y polimorfismo para gestionar distintos canales de comunicación.

El ejercicio implementa una interfaz `CanalNotificacion` y tres clases concretas: Email, SMS y Push. Además, incorpora un `GestorAlertas` que permite realizar envíos masivos y selectivos mediante una lista de canales.
